# Code of Conduct

## Our standard

Be direct, be useful, don't be a jerk about it. This project exists to help people learn and do authorized
security work better. Disagreements about code and architecture are fine and expected; personal attacks,
harassment, and discrimination are not, and will get you removed from the project's spaces (issues, PRs,
discussions) without much discussion.

## Scope

This applies to all project spaces (issues, pull requests, discussions, and any other official HexSwarm
channel), and to anyone representing the project in public.

## A specific note for this project

HexSwarm is an offensive-security tool. "I'm just testing it" is not an exception to the law or to platform
terms of service. Do not use project spaces to request help attacking a system you don't own or don't have
explicit written authorization to test, and do not post real, working exploitation walkthroughs against
unauthorized targets. Contributions that add tooling should stay general-purpose (a wrapper around a named
CLI tool, a scope-aware adapter) rather than a pre-built attack chain against a specific named organization.

## Reporting

Report conduct issues to **nexaforge.services@gmail.com**. Reports are handled privately and in confidence.

## Enforcement

Maintainers may remove comments, commits, code, issues, and other contributions that violate this code, and
may temporarily or permanently ban anyone for behavior they deem inappropriate, threatening, or harmful.
